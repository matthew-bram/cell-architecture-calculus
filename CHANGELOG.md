# Changelog

This changelog has one row per decision, newest first. The calculus's version is in `cell-calculus/lakefile.toml` and moves by supersession.

| Date | What changed | Why |
| --- | --- | --- |
| 2026-11-06 | A change to the calculus may be proposed because published practice has moved, not only because a project needs a shape. A public shape may be retired with no successor, deprecated with the date and the reason. The contributor's guide, the agent's guide, the style guide, the README, `future/README.md`, the issue form and the pull request template say so | The owner's decision: the calculus changes as the state of the art does, and practice can drop a pattern without replacing it. The README already said a change arrives when practice moves, while the contributor's guide and the issue form allowed only a project's need |
| 2026-11-01 | The authorship skill covers the documents outside the skills and says nothing about when to commit or push. It still shapes how commit messages and pull request descriptions read | The owner's decision: a skill is a technical procedure, not a document for readers, and when to commit and push is the engineer's call |
| 2026-11-01 | A branch takes as many commits as the work needs and is pushed when the change is ready for a pull request. The rule of one commit per step is gone | The owner's decision: a branch's commits track how a change evolved, and the squash merge already makes each pull request one commit on `main` |
| 2026-11-01 | A statement that a change to the model makes false is not a theorem: the build rejects it, and it is removed, never deprecated, restated under its name or replaced by a theorem that it now fails, while the example it proved is retired with its successor. The style guide, the calculus document, the lifecycle, the white paper and the change-a-model skill say so | The skill's checklist replaced such a theorem with a `_retired` one that proved it now failed, while the style guide and the skill's own list said a theorem is never deleted, so the skill's evaluation failed on every run. The owner ruled that a theorem the build cannot prove is not a theorem, and "never deleted" governs the ones it can |
